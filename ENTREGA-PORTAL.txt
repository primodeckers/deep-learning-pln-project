O QUE O PROJETO FAZ
-------------------
Classificação textual (PLN) do campo Objeto de editais/compras em macroáreas
de gasto (Saúde, Saneamento, Segurança, Educação, Infraestrutura/Obras,
Administração/Outros).

Dois corpora:
  - ComprasNet HTML: 423 editais (entrega oficial)
    Melhor modelo: TF-IDF + LogReg (F1 macro teste 0,74)
  - PNCP DF/2025: 19.944 compras (extensão em escala)
    Melhor modelo: BERTimbau (F1 macro teste 0,86 no protocolo pncp)

Escopo: somente classificação. Sumarização não faz parte desta entrega.
Dados inéditos coletados pelo grupo (sem bases prontas / Kaggle).

COMO REPRODUZIR (resumo)
------------------------
Python 3.10+

  python -m venv .venv
  source .venv/Scripts/activate          # Git Bash (Windows)
  pip install -r requirements-dev.txt
  pip install -e ".[bert]"               # opcional, para BERTimbau

ComprasNet (entrega oficial):

  python scripts/run_collect.py
  python scripts/run_preprocess.py
  python scripts/run_train.py --model baseline

PNCP (extensão):

  python scripts/run_preprocess_pncp.py
  python scripts/run_train.py --model bertimbau \
    --config configs/classification_pncp.yaml \
    --corpus data/processed/pncp_corpus_df2025.jsonl

Testes:

  pytest

Instruções completas: README.md na raiz do repositório.

MODELOS COMPARADOS
------------------
1) TF-IDF + Regressão Logística  (ML clássico — modelo principal no ComprasNet)
2) TF-IDF + SVM linear           (ML clássico — comparativo)
3) BERTimbau (Transformer)       (deep learning — melhor no PNCP em escala)

Não utilizamos CNN nem RNN/LSTM; o experimento de deep learning é o Transformer.
